Hartono Household Budget is a working household budget site for the Hartono family of Jakarta in November 2026: a dashboard with real income, spending and savings figures, an editable budget, 24 real transactions, four savings goals with a simulator, three live calculators (50/30/20, emergency fund, loan instalments), a six-month report and a budgeting guide. Everything runs from static files with no network request.

## Run it

```sh
node serve.ts
```
(lalu buka http://localhost:8080 — atau buka app/index.html langsung di browser)
